# getlake.dev

The Lake website, served on GitHub Pages as the getlake user site.

- https://getlake.dev/: this repo
- https://getlake.dev/lake-meter/: [lake-meter](https://github.com/getlake/lake-meter) project Pages
- https://getlake.dev/lake-gate/: [lake-gate](https://github.com/getlake/lake-gate) project Pages
