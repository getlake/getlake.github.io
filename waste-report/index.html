Claude Code waste report

Send us your team's Claude Code usage export. Within 24 hours you get a PDF that shows where tokens and money went to waste, and what to change first. For eng leads, managers and whoever owns the AI budget.

Request your report See a sample PDF

What the report shows

  • Rework: sessions that burned tokens on work that was redone or thrown away, and roughly what that cost.
  • Oversized models: small steps run on the biggest, most expensive model, and what a cheaper pick would have cost.
  • Runaway runs: sessions and days far above your normal spend, the loops and retries that nobody stopped.
  • Missing plan review: large runs that started with no agreed plan, where a quick review would have been the cheapest place to say no.
  • What to fix first: a short, ranked list of changes, with the spend each one touches.

Figures come from your own export. Where we estimate (for example, what a smaller model would have cost), the report says so.

What to send

The easiest export is from ccusage, a free open-source tool that reads the local Claude Code logs on each developer's machine and prints token and cost totals. Run it on each machine you want included:

npx ccusage@latest claude session --json --breakdown > claude-sessions.json
npx ccusage@latest claude daily --json --breakdown > claude-daily.json
  • Add --since YYYYMMDD to limit the period. The last 30 days is plenty.
  • The output holds dates, models, token counts, costs and session and project identifiers. Rename or remove project names first if they are sensitive.
  • If your team uses API keys, a usage or cost CSV exported from the Claude Console works too.
  • Please do not send the raw log files under ~/.claude/projects. They contain your prompts and code, and we do not want them.

Privacy

  • We only read token, model and cost metadata. We do not need, and do not ask for, prompts or code.
  • We use your files only to write your report, and delete them after we send it.
  • We keep your name and email to reply, as described in our Privacy Policy. No newsletter, no sharing.
